# Запуск сервиса в Docker

Этот документ описывает, как собрать и запустить Encrypted Pastebin в контейнере Docker, а также особенности хранения данных и безопасности.

---

## 1. Требования

- Установленный **Docker** (проверить: `docker --version`)
- Установленный **Docker Compose** v2 (проверить: `docker compose version`)

Проверить доступность:

```bash
docker --version && docker compose version
```

Если команды не найдены — установите Docker согласно [официальной документации](https://docs.docker.com/engine/install/).

---

## 2. Быстрый старт

Из корня проекта выполните:

```bash
# Сборка образа и запуск контейнера в фоне
docker compose up -d --build
```

Сервис будет доступен на **http://localhost:3000** (порт берётся из переменной `PORT` в `.env`, по умолчанию 3000).

Интерактивная документация API (Swagger UI) — на **http://localhost:3000/api-docs/**.

Проверить, что контейнер запущен:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f
```

---

## 3. Конфигурация

Переменные подхватываются из файла `.env`, лежащего рядом с `docker-compose.yml`. Создайте его из шаблона при необходимости:

```bash
cp .env.example .env
```

| Переменная           | Описание                                                              | По умолчанию   |
|----------------------|-----------------------------------------------------------------------|----------------|
| `PORT`               | Порт на хосте, который маппится на порт 3000 контейнера              | `3000`         |
| `SESSION_SECRET`     | Секрет подписи сессий (обязательно свой для production)              | `dev-secret`   |
| `ENCRYPTION_KEY`     | Ключ шифрования AES-256 (hex, 32 байта)                               | пусто (авто)   |
| `BASE_URL`           | Внешний URL сервиса (если за reverse-proxy)                           | автоопределение |
| `BASE_PATH`          | Базовый путь при работе по под-пути, напр. `/pastebin` (nginx)        | пусто (корень) |
| `REGISTRATION_DISABLED` | Отключить регистрацию новых пользователей (`true`/`false`)        | `false`        |

> Переменная `DATA_DIR` внутри контейнера не меняется — данные всегда лежат в `/app/data` (том `pastebin-data`).

Пример `.env` для production:

```
PORT=8080
SESSION_SECRET=my-very-long-and-secure-session-secret
ENCRYPTION_KEY=0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
BASE_URL=https://paste.example.com
```

## 4. Работа за nginx по под-пути

Сервис умеет работать по ссылке вида `https://хост/<путь>/` (например `/pastebin`).

**Базовый путь определяется автоматически** (сервером из URL запроса):
- если nginx **срезает** префикс (`proxy_pass ...;` с завершающим слешем) — настройка **не требуется**;
- если nginx **не срезает** префикс (передаёт под-путь на бэкенд, `proxy_pass http://127.0.0.1:3000;` без завершающего слеша) — также **настройка не требуется**: префикс распознаётся автоматически. При желании его можно зафиксировать явно:

```bash
BASE_PATH=/pastebin
```

Все адреса (статика, API, страницы `/p/:slug`, Swagger `/api-docs`) автоматически получат нужный префикс.

Пример nginx (без срезания префикса, HTTPS):

```nginx
location /pastebin/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 5. Хранение данных

Данные хранятся в **именованном томе** `pastebin-data`, смонтированном в `/app/data`:

- `pastebin.db` — база данных SQLite (пользователи, метаданные записей);
- `secret.key` — ключ шифрования AES-256 (генерируется автоматически, если не задан `ENCRYPTION_KEY`);
- `pastes/` — зашифрованные файлы записей.

Том переживает перезапуски и пересборки контейнера.

Полезные команды:

```bash
docker compose down          # остановить контейнер (данные сохраняются)
docker compose restart       # перезапустить
docker volume ls             # посмотреть тома
docker volume inspect pastebin-data   # посмотреть место хранения тома
```

> **Внимание:** `docker compose down -v` удаляет том вместе со всеми данными.

---

## 5. Ключ шифрования и безопасность

- Если переменная `ENCRYPTION_KEY` **не задана**, ключ генерируется один раз и сохраняется в `secret.key` внутри тома.
- **Потеря ключа** (удаление тома без зафиксированного `ENCRYPTION_KEY`) делает **все ранее созданные записи нерасшифровываемыми**.
- Для production:
  - обязательно задайте собственный `SESSION_SECRET`;
  - задайте фиксированный `ENCRYPTION_KEY` (32 байта в hex), чтобы данные были читаемы после пересоздания тома.

Сгенерировать 64-символьный hex-ключ можно командой:

```bash
openssl rand -hex 32
```

---

## 6. Сборка образа вручную (без Compose)

Если нужен только Dockerfile:

```bash
docker build -t encrypted-pastebin .

docker run -d \
  --name pastebin \
  -p 3000:3000 \
  -e SESSION_SECRET='change-me' \
  -v pastebin-data:/app/data \
  encrypted-pastebin
```

---

## 7. Особенности Dockerfile

- **Многоступенчатая сборка**: зависимости устанавливаются в промежуточном образе, в финальный копируются только `node_modules`, `src/` и `public/`.
- **Нативный модуль `better-sqlite3`** компилируется внутри образа на этапе сборки (добавлены `python3 make g++`), поэтому в рантайме не требуется toolchain.
- **Swagger-документация** (чисто JS-пакет `swagger-ui-express`) копируется вместе с `src/` и не требует дополнительного toolchain; интерактивная документация доступна на `/api-docs/`.
- Контейнер запускается от **непривилегированного пользователя** `node` (не root).
- Объявлены порт `3000` и том `/app/data`.

---

## 8. Частые операции

| Действие                        | Команда                                    |
|---------------------------------|--------------------------------------------|
| Сборка и запуск                 | `docker compose up -d --build`             |
| Остановка (данные сохраняются)  | `docker compose down`                      |
| Полное удаление (с данными)     | `docker compose down -v`                   |
| Перезапуск                      | `docker compose restart`                   |
| Логи                            | `docker compose logs -f`                   |
| Статус                          | `docker compose ps`                        |

docker save encrypted-pastebin:latest | gzip | ssh zago@zago.404.mn -p 11022 'docker load'
